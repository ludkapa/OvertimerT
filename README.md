# ⏱️ OvertimerT

![Rust](https://img.shields.io/badge/Rust-000000?style=for-the-badge&logo=rust&logoColor=white)
![Teloxide](https://img.shields.io/badge/Teloxide-blue?style=for-the-badge&logo=telegram)
![rust-xlsxwriter](https://img.shields.io/badge/rust--xlsxwriter-green?style=for-the-badge)

**OvertimerT** — это инструмент для автоматической генерации Excel-таблиц, предназначенный для подсчёта переработок и итогового заработка сотрудников. Управление процессом происходит через удобного Telegram-бота с возможностью гибкой настройки смен.

## ✨ Основные возможности
* **Генерация Excel-файлов:** Быстрое создание форматированных отчетов с использованием `rust-xlsxwriter`.
* **Telegram-интерфейс:** Полное управление через бота на базе фреймворка `teloxide`.
* **Умный расчет:** Автоматическое выставление ночных и дневных смен, а также корректный подсчет переработанных часов (включая выходные и праздники).
* **Интеграция праздников:** Автоматическое получение актуальных данных о праздничных днях.
* **Чистота чата:** Бот автоматически удаляет промежуточные сообщения, чтобы не засорять историю переписки.

## 🚀 Использование
Взаимодействие с ботом максимально интуитивное:
1. Найдите бота в Telegram и напишите ему любое сообщение.
2. Бот предложит выбрать параметры для генерации таблицы.
3. Следуйте подсказкам на экране (настройка дневных/ночных смен) и получите готовый Excel-файл прямо в чат.

## 🛠 Установка и запуск

Бот работает через **Webhook**, поэтому для полноценного запуска на сервере потребуется настроенный домен и SSL-сертификат (например, связка Nginx + Let's Encrypt).

### 1. Локальная сборка
Клонируйте репозиторий на свою машину:
```bash
git clone <ссылка_на_ваш_репозиторий>
cd <название_папки>
```

Скомпилируйте код в release-режиме:
```bash
cargo build --release
```

### 2. Подготовка сервера
Перенесите получившийся бинарный файл (из `target/release/`) на ваш сервер. Рядом с исполняемым файлом создайте файл `.env`. Вы можете использовать `.env_template` в качестве примера:

```env
# Пример содержимого .env
OT_TOKEN=ваш_токен_от_BotFather
OT_WEBHOOK_URL=https://ваш_[домен.com/webhook_path](https://домен.com/webhook_path)
```

### 3. Запуск
Настройте reverse-proxy на сервере так, чтобы он перенаправлял запросы с `WEBHOOK_URL` на локальный порт вашего бота. После этого запустите бинарник:
```bash
./OvertimerT
```
*(Для работы в фоновом режиме рекомендуется настроить systemd-сервис или использовать tmux/screen).*
